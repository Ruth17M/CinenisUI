# Examen Final – Programación para la plataforma OSX

## Descripción del Tema

Este proyecto consiste en el desarrollo de una aplicación para macOS para un cine. La aplicación permite a los usuarios seleccionar la película, el horario de la función y elegir sus asientos. La aplicación fue desarrollada utilizando SwiftUI y se conecta a una API RESTful construida con Vapor, desplegada en la nube y conectada a una base de datos MySQL.

## Instrucciones para Probar el Proyecto

### 1. Clonar el Repositorio

Para probar el proyecto, primero clona ek repositorio de la App de macOS de GitHub:

- **Repositorio de la App de macOS**: [Enlace al repositorio de macOS](https://github.com/Ruth17M/CinenisUI)
- **Repositorio de la API con Vapor**: [Enlace al repositorio de Vapor API](https://github.com/marianaortizzz/CinenisAPI)


### 2. Ejecutar la Aplicación de macOS

1. Abre el proyecto de la app de macOS en Xcode.
2. Ejecuta la app en un simulador de macOS.
3. La aplicación te permitirá:
   - Elegir la película que deseas ver.
   - Seleccionar el horario de la función.
   - Elegir tus asientos dentro de la sala de cine.

### 3. Interacción con la API

La app consume la API utilizando `URLSession` y las funcionalidades de `async/await` para hacer peticiones HTTP y manejar las respuestas de la API de forma eficiente.
